# 团队工作台本地交付验收

日期 2026 年 11 月 12 日。需求基准为 [PRD 1.1](PRD_TEAM_WORKBENCH_V1.md)，改造前代码为 bc912b69f48b6827a1522302dcaf765e1c5ec63a。此次实现针对单工作区、单机内部团队，不构成生产 SLA 或真实客户使用证明。

## 交付行为

团队网页已接入真实 /v1：资料目录与历史、新建及更新文件导入、可恢复任务、待审队列、原文校订、条件复核发布、证据回读和校验、用户与知识库授权、本人 Agent 令牌、健康状态与审计。之前的独立教学原型不作为运行依赖。

后端增加 6 类分页读接口、签名 cursor 与必要索引；只读目录隐藏尚未公开的来源，Agent 令牌不能读取待审管理内容。任务、修订与选中知识库进行一致性检查。停用本人管理账户被服务端拒绝。前端代码按任务拆成独立模块，没有新增运行时构建链或数据库。

## 测试范围

改造前 289 项 Python 通过。改造后 307 项 Python 通过，新增 18 项覆盖分页、身份与接口绑定、过期和 ACL 变化、未发布隔离、管理元数据、重启留存和角色写入限制。原有 68 项 Node 测试全部通过。

Python 为本机 3.13.5，复用已缓存、与项目直接依赖版本一致的隔离依赖；未宣称本次做了联网干净安装。浏览器采用本机 Chrome 与 Playwright。真实验证服务只监听回环地址，使用随机生成的凭证和虚构售后文本，不读取任何项目 .env，也不访问已有真实业务数据目录。

浏览器覆盖新建、v2 更新、任务刷新、并发编辑冲突、审核发布、旧引用失效、令牌撤销、reader 拒绝管理请求和手机显示。多页 PDF 解析沿用原有服务，界面按 page_count 逐页读取；本轮浏览器主流程使用单页文本，没有把大型 PDF、所有格式和所有设备都描述为已完整试用。正式资料需要在试点中补充格式与容量验收。

备份恢复在全新隔离目录执行，核对数据库、原始文件、已发布 v2 与成员授权。它证明本轮样例可恢复，不替代正式环境的备份计划、保留期或恢复时间承诺。

## 上线门禁

目标服务器未提供，因此 TLS、受信任代理头、服务账户权限、进程自动恢复、外部告警、定时与隔离备份、磁盘不足、实际容量、RPO/RTO 和真实人员试用保持待现场验收。双人强制审批、多租户、单点登录与多机高可用不在本版范围。

浏览器截图均来自本轮隔离服务中的虚构资料与生成账户。它们展示真实本地接口行为，不是线上客户截图。
