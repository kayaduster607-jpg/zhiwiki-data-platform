# 孤儿上传候选报告

导入入队失败时，文件可能已保存但尚无修订记录。可使用只读报告识别需要人工核查的候选文件：

```powershell
python -B -m zhiwiki.service.orphan_report --config config.team.example.json --grace-hours 24
```

工具只检查 `uploads` 下符合 64 位小写 SHA-256 文件名、且修改时间超过宽限期的普通文件，再排除 `team_revisions` 中所有已引用的 hash。宽限期最少一小时；默认 24 小时。它不读取文件内容，不创建数据库，也不删除或移动文件。`.pending`、非 hash 名称和符号链接不纳入候选。

**报告不代表可以直接删除。** 报告使用数据库只读快照，但文件系统和数据库不是统一快照；服务或 worker 运行时，文件可能在报告后被引用。当前仅 API 有排他锁，worker 没有与之共享的维护锁，因此本项目暂不提供自动删除。需要先设计覆盖 API、worker、维护任务和备份的统一排他协议，再验证并发与崩溃恢复，才能安全支持清理。

报告结果只在本地输出文件 hash、大小、修改时间和汇总，不包含上传正文。请选择真实部署的显式 JSON 配置；本命令不会读取 `.env`。
