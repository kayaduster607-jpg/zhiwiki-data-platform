# 团队网页使用与维护

本版团队服务直接提供真实网页。仍只运行一个团队 API 进程和独立 worker，不使用前端开发服务器，不需要 npm 构建。页面与 API 同源，静态脚本只通过明确白名单提供。

产品范围和验收要求见 [团队工作台 PRD](PRD_TEAM_WORKBENCH_V1.md)。

## 运行

首次准备配置与管理员的方法沿用 [团队服务手册](TEAM_SERVICE.md)。本机演示分别执行：

```powershell
python -B -m zhiwiki.service --config config.team.example.json serve --port 8872 --local-http
python -B -m zhiwiki.service --config config.team.example.json worker
```

打开 http://127.0.0.1:8872 登录。这里的非 Secure Cookie 只用于回环开发。正式部署采用 HTTPS、明确受信任 Host 和反向代理，参阅 [部署预检](DEPLOYMENT_PREFLIGHT.md)。不要将本地工作台与团队服务连接到同一数据目录。

## 完成一份资料的发布

管理员在账号与接入中创建知识库、用户并分配角色。editor 导入新来源，填写稳定来源键；新文件先进入持久任务。任务列表和详情会显示真实处理状态，地址可在刷新后重新进入。

解析后在复核与发布中核对原始抽取与当前正文。选择页码时只读取这一页。必要时填写说明并保存校订；保存会撤销旧复核。publisher 填写说明，明确复核后再确认发布。资料目录中的公开版本以服务端结果为准。

更新资料时从目录选择导入新版，保留同一来源键，并使用当前公开修订作为前置条件。旧版在新稿处理时继续提供服务；发布后的历史修订保留。编辑冲突时正文保留在页面中，重新读取前会提示确认，不能无声覆盖。

## 检索与引用

在检索与取证中取得已发布证据，回读原文并校验引用。资料更新、权限撤销或凭据过期后，应重新检索。页面保留的快照仅存在内存中，刷新、切换知识库或退出后不会从浏览器持久存储恢复。

校验只确认版本、内容和当前访问条件。semantic_support 为 not_checked，不能据此断言原文充分支持生成答案。团队服务仍不调用大模型。

## 令牌与账号

本人可创建指定知识库的只读 Agent 令牌，选择 retrieve、read、validate 和可选 download 范围。新明文只显示一次，离开后清除；保存后可主动清除显示。列表只显示 token_id、范围、到期和撤销状态。

token_id 是管理标识，不能作为 Bearer 明文使用。Agent 令牌不能访问工作台管理列表和未公开修订，即使令牌所有者是编辑员或系统管理员。需要管理资料时通过浏览器会话完成。

只有全局管理员可管理用户和成员；知识库 admin 只是库内角色。系统拒绝停用当前自己的管理账户。首次管理员的恢复应按既有受控运维流程处理，不在网页中添加绕过认证的后门。

## 查询与兼容性

新增任务、待审、历史、用户、成员和令牌列表都限制为每页 1 至 100 条。新增 cursor 绑定身份、接口、过滤、分页大小与权限语境，10 分钟过期。权限或查询条件变化后返回第一页刷新。分页期间新增或状态变化需要刷新，不提供冻结快照保证。

原有 /v1 响应保持 schema_version 1.0，新增字段为向后兼容扩展。以下为有意收紧的访问行为：reader 目录不展示未公开来源；任务详情仅面向编辑级浏览器会话；非当前公开修订不能由 Agent Bearer 访问。原文取证工具继续只服务授权公开内容。

## 运维

运行与审计页面返回真实健康检查、worker 心跳、现有资源指标与审计。进程内计数会在重启后归零；心跳不证明解析器容量。页面不会把未接入的外部告警、TLS、备份计划和恢复演练标记为完成。

备份和恢复继续使用 CLI，在隔离空目录恢复后核对原文件、授权和检索，不从网页提交任意磁盘路径。现场仍需完成备份计划、异地或隔离副本、告警接入、进程管理和容量测量。

## 验证

```powershell
python -B -m pytest -q -p no:cacheprovider
node --test tests/*.cjs
```

新增浏览器验证脚本使用真实 API、独立 worker 和虚构资料，随机生成账号密码并只通过进程内存传递，不读取项目 .env。它还执行数据库、原文件与授权的备份恢复。浏览器依赖是可选验证工具，不是运行服务的前置条件：

```powershell
python -B scripts/verify_team_workbench.py --output reports/local-workbench --node PATH_TO_NODE --playwright-module PATH_TO_PLAYWRIGHT --browser PATH_TO_CHROME
```

替换三个 PATH 参数为本机已安装工具位置；若 Playwright 可直接从 Node 解析，可省略 --playwright-module。报告与生成数据写入指定目录，使用全新随机子目录，不覆盖既有业务资料。验证只监听回环地址，不提供默认账号或固定密码。

可加 --record-video 录制带中文步骤说明、遮挡令牌明文的演示，再使用 scripts/export_team_demo.py 导出 MP4。成片和完整复现步骤见[视频说明](DEMO_VIDEO.md)。
