# 团队服务接入 CSV 与 JSON

团队服务支持以 UTF-8 CSV 或 JSON 文件作为资料接入，沿用 `/v1/workspaces/default/uploads`，而非开放本地工作台的 `/api/*`。上传者必须具备目标知识库的导入权限；调用需提供目标库、来源键及幂等键。更新现有资料时还须提供当前文档 ID 和预期版本，具体参数见 [团队服务手册](TEAM_SERVICE.md)。

## 处理与发布

1. 上传接口限制文件不超过 2 MiB，返回持久任务 ID；该响应只表示任务已接收，并不表示文件解析或发布成功。
2. 独立 worker 对非 PDF 文件进行解析。CSV 检查引号等基础语法；JSON 检查语法并拒绝 `NaN`、`Infinity` 等非标准数值。正文最多 500,000 个字符；不符合条件的任务进入失败状态，不能复核发布。
3. 原始文件按内容哈希保存，授权下载可回读原始字节；资料页保存可检索文本和来源。UTF-8 BOM 在解码文本中会去除，但保留于原文件。CSV 内嵌换行和 JSON 格式不在解析时重排。
4. 版本按既有流程由授权人员检查、复核后条件发布。更新创建新版本，历史原文件仍可按权限回读。

## 使用边界

- CSV/JSON 以**文档原文**存储与检索；没有表结构映射、类型转换、行级权限、SQL 数据库接入或增量同步。
- 基础格式检查不验证业务字段、数据真实性、完整性或安全性。字段质量问题应结合业务规则与人工复核处理。
- 原文件、文档和质量结果可能含敏感数据，必须按现有知识库权限和企业数据保留策略管理；不要将测试数据当作真实生产数据。
- 数据来源、服务容量、备份恢复及实际部署环境仍需针对现场验收；通过本地测试不代表达到企业生产级 SLA。
